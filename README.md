# XO LAB

XO LAB is a local-first video effects editor with depth/dust processing, blob tracking, audio-reactive effects, 3D model import, and video export. The web app is packaged for iPhone with Capacitor; the original editor remains in `dist/`.

## Run the web app

Serve `dist/` from a local web server. For example, with Python:

```sh
python3 -m http.server 4173 --directory dist
```

## Build the iOS project locally

Requirements: Node.js 22, npm, macOS, and Xcode 26 or later.

```sh
npm ci
npx cap add ios
npx cap sync ios
npx cap open ios
```

The iOS project is generated by the pinned Capacitor CLI during the build. User media and imported 3D files are selected from the device and processed by the app; they are not uploaded by this project.

## Build an unsigned iPhone IPA with GitHub Actions

Open **Actions → Build XO LAB (Unsigned IPA) → Run workflow**, or push a commit to `main`. GitHub builds the app for a real iPhone device, packages it as `XO-LAB-unsigned.ipa`, checks the package structure and ARM64 executable, and uploads it as the `XO-LAB-unsigned-IPA` artifact.

Download the artifact from the completed workflow run’s **Artifacts** section. The IPA is unsigned; install it through the same sideloading tool used for XO-METER, which signs it for your device during installation. It is not an App Store or TestFlight package and cannot be installed by tapping the file in Files.

## Current limitations

- The workflow creates an unsigned device IPA; the sideloading tool must sign it before installation.
- iOS device behavior for model decoding, WebGL performance, and MP4 recording still needs to be checked on a physical iPhone after installation.
