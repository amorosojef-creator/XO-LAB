# XO LAB

XO LAB is a local-first video effects editor with depth/dust processing, blob tracking, audio-reactive effects, 3D model import, and video export. The web app is packaged for iPhone with Capacitor; the original editor remains in `dist/`.

## Run the web app

Serve `dist/` from a local web server. For example, with Python:

```sh
python3 -m http.server 4173 --directory dist
```

## Build the iOS project locally

Requirements: Node.js 22, npm, macOS, and Xcode 26 or later.

```sh
npm ci
npx cap add ios
npx cap sync ios
npx cap open ios
```

The iOS project is generated by the pinned Capacitor CLI during the build. User media and imported 3D files are selected from the device and processed by the app; they are not uploaded by this project.

## GitHub Actions builds

Open **Actions → Build XO LAB for iPhone → Run workflow**. Without signing secrets, the workflow builds and uploads a **Simulator-only** app for inspection; it does not create an installable IPA. With signing secrets configured, it archives and exports an ad-hoc signed IPA, then uploads it as the `XO-LAB-iPhone-IPA` workflow artifact. Publishing a GitHub Release also attaches the IPA to that release.

Configure these repository Actions secrets to create a device-installable IPA:

| Secret | Value |
| --- | --- |
| `IOS_CERTIFICATE_P12_BASE64` | Base64-encoded Apple Distribution `.p12` certificate |
| `IOS_CERTIFICATE_PASSWORD` | Password used to export the `.p12` certificate |
| `IOS_PROVISIONING_PROFILE_BASE64` | Base64-encoded Ad Hoc provisioning profile for `com.floroxo.xolab` |
| `IOS_TEAM_ID` | Apple Developer Team ID |

The Ad Hoc profile must include the iPhone UDIDs where you plan to install the IPA. Never commit signing materials or paste secrets into issues or chat. After saving the secrets, run the workflow again. Download the IPA from the completed run’s **Artifacts** section, or publish a release to attach the IPA directly.

## Current limitations

- A signed IPA requires a valid Apple Developer signing certificate and matching Ad Hoc provisioning profile. Without these, only the Simulator artifact is produced.
- iOS device behavior for model decoding, WebGL performance, and MP4 recording still needs to be checked on a physical iPhone after installation.
